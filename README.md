# Phishing URL Detection

A machine learning project for phishing URL classification.

## Models
- Logistic Regression
- Random Forest Classifier

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn

## How to Run
1. Install the required Python packages.
2. Download the PhiUSIIL Phishing URL Dataset.
3. Update the dataset path in preprocess.py.
4. Run:

   python preprocess.py
